## Задача

Дан непустой отсортированный список целых чисел `nums`. Нужно изменить сам список так, чтобы в его первых `k` позициях каждое число встречалось один раз, а порядок чисел сохранился. Метод должен вернуть `k` — количество уникальных элементов. Содержимое списка после первых `k` позиций может быть любым.

## Решение

В файле `solution.py` задача решена методом `removeDuplicates` класса `Solution`. Я использую два индекса. Индекс `i` показывает, какой элемент я сейчас читаю, а `j` указывает на последний записанный уникальный элемент.

Первый элемент уже стоит на своём месте, поэтому я начинаю с `j = 0` и прохожу по списку с индекса `1`. Если `nums[i]` равно `nums[j]`, пропускаю повтор. Иначе записываю `nums[i]` в `nums[j + 1]` и увеличиваю `j` на единицу. В конце возвращаю `j + 1`, потому что индексы начинаются с нуля.

## Почему это работает

До начала цикла первый элемент уже образует начало списка из одного уникального числа. На каждом шаге в позициях от `0` до `j` лежат все уникальные числа, которые уже встретились при обходе, в исходном порядке.

Список отсортирован, поэтому одинаковые числа идут подряд. Если текущее число равно последнему записанному, это повтор. Если оно отличается, его нужно записать сразу после последнего уникального элемента. Позиция записи находится на текущей или уже просмотренной позиции, поэтому элементы впереди цикла сохраняются.

После обхода все уникальные числа занимают позиции от `0` до `j`. Их количество равно `j + 1`.

## Сложность

- Время — **O(n)**. Я прохожу по списку один раз.
- Дополнительная память — **O(1)**. Я использую два индекса и записываю результат в исходный список.

## Примеры

| Исходный `nums` | Результат `k` | Первые `k` элементов после вызова |
|---|---:|---|
| `[1, 1, 2, 2, 4]` | 3 | `[1, 2, 4]` |
| `[7, 7, 7]` | 1 | `[7]` |
| `[-3, 0, 2]` | 3 | `[-3, 0, 2]` |
| `[5]` | 1 | `[5]` |
